# `_studio/docs` — instructor reference

The studio route's four hand-in documents, filled with this machine's dated
numbers (2026-11-05, headless Chrome on SwiftShader; see each file):

- `ktx2-note.md` — the KTX2 choice: file bytes (suitcase) and computed GPU bytes
  (room) for PNG, ETC1S and UASTC, `texture.format`, the texture count, the
  orientation and colorSpace checks, and the exact encode commands.
- `renderer-info.md` — the panel's `renderer.info` rows per switch mode and the
  accepted `CEILING`.
- `shader-note.md` — the Unit 9 checklist for `src/SleeveMaterial.jsx`.
- `ai-3d-merge-log.md` — what the AI agent that drafted this route accepted
  and rejected, with evidence. It is not a human review.

`_studio` ships original art only (D8): `public/sleeve.png` is painted by
`tools/make-sleeve.mjs` from `src/palette.js`. Students copy `covers/_template/`
to light their own route; they do not fork `_studio`.
